# 카카오 로그인 연결

2026-11-08 현재 PC에서 MathSite 전용 앱(ID 1641477)을 등록하고 카카오 로그인 활성화·복귀 주소·서버 키를 설정했다. 실제 카카오 로그인에서 인가 코드 교환·회원번호 조회·사이트 관리자 로그인까지 확인했다. 프로젝트 소유자의 카카오 회원은 기존 관리자로 인증한 관리 API를 통해 승인·관리자 지정했으며, 일반 신규 카카오 회원은 계속 승인 대기 학생으로 가입한다. 자동 테스트의 공급자 응답 대체와 실계정 로그인 확인은 별도다.

## 1. 카카오 개발자 앱 만들기

1. https://developers.kakao.com 에서 본인 카카오 계정으로 로그인한다.
2. 앱을 추가한다. 앱 이름은 `MathSite`로 정하면 된다. 개발자 등록이나 약관 동의가 나타나면 본인이 내용을 확인하고 진행한다.
3. 해당 앱의 **카카오 로그인 → 일반**에서 카카오 로그인을 활성화한다.
4. **앱 → 플랫폼 키 → REST API 키**에서 다음 Redirect URI를 등록한다.

```text
http://127.0.0.1:3000/auth/kakao/callback
```

5. 같은 REST API 키의 **Client Secret**은 활성화 상태로 사용한다. 키와 시크릿을 아래 로컬 설정에 입력한다. JavaScript 키나 Admin 키를 입력하지 않는다.

이 프로젝트는 REST API 인가 코드 방식이다. 카카오 프로필 이름·이메일 동의항목은 요구하지 않으며 사이트 가입 시 이름과 이메일을 직접 입력받는다. OpenID Connect는 이 구현에서 사용하지 않는다.

공식 설정 안내: https://developers.kakao.com/docs/ko/kakaologin/prerequisite
공식 REST API 안내: https://developers.kakao.com/docs/ko/kakaologin/rest-api

## 2. 로컬 설정

프로젝트 `.env`의 마지막 항목을 채운다. 실제 값은 채팅·소스·공유 압축파일에 넣지 않는다.

```dotenv
KAKAO_REST_API_KEY=앱의_REST_API_키
KAKAO_CLIENT_SECRET=활성화된_Client_Secret
KAKAO_REDIRECT_URI=http://127.0.0.1:3000/auth/kakao/callback
```

서버를 재시작한 뒤 `http://127.0.0.1:3000/`를 연다. `localhost`와 `127.0.0.1`은 쿠키 기준으로 다른 호스트다. 로그인·연결·callback을 모두 위의 `127.0.0.1` 주소에서 진행한다.

```powershell
npm.cmd run db:init
npm.cmd start
```

`db:init`은 새 카카오 연결 테이블을 추가하고 기존 회원·강좌·시청 권한은 유지한다. `GET /api/auth/kakao/status`의 `configured: true`는 필수 설정이 입력됐다는 뜻이다. 카카오가 키와 URI를 실제 승인했는지는 로그인 완료로 확인한다.

## 3. 관리자와 학생 연결

**기존 관리자:** 이메일로 기존 관리자 계정에 로그인 → `현재 계정에 카카오 연결` → 카카오 인증 완료. 이후 카카오 로그인으로도 기존 관리자 계정에 접속한다. 처음 로그인했다는 이유로 관리자가 되지 않는다.

**기존 학생:** 본인 이메일 계정에 로그인한 뒤 같은 연결 버튼을 사용한다. 기존 강의 시청 권한을 유지한다.

**신규 학생:** 카카오로 로그인 → 이름·이메일 입력 → 승인 대기로 등록. 관리자가 `신규 회원 승인·정지`에서 승인하고 별도로 강의 시청 권한을 부여한다. 같은 이메일의 기존 계정이 있으면 가입을 거절하고 기존 계정 로그인 후 연결하게 한다. 직접 입력한 이메일은 카카오 인증 이메일이라는 뜻이 아니다.

로그아웃은 **MathSite 세션 종료**다. 카카오 계정 자체의 로그인 상태나 앱 연결 동의를 해제하지 않는다. 토큰은 회원번호 확인에만 사용하고 DB·브라우저·로그에 저장하지 않는다.

## API

| 메서드 | 경로                       | 역할                                                 |
| ------ | -------------------------- | ---------------------------------------------------- |
| GET    | `/api/auth/kakao/status`   | 설정·추가 가입 정보 필요 여부·현재 계정 연결 여부    |
| GET    | `/auth/kakao`              | 카카오 로그인 시작                                   |
| GET    | `/auth/kakao/link`         | 로그인한 기존 계정에 카카오 연결 시작                |
| GET    | `/auth/kakao/callback`     | state 확인 → 토큰 교환 → 회원번호 조회 → 사이트 세션 |
| POST   | `/api/auth/kakao/register` | 인증 후 이름·이메일로 승인 대기 학생 가입            |

state와 임시 가입 정보는 서버 세션에 10분간 보관한다. 세션 쿠키는 HttpOnly·SameSite=Lax로 카카오의 최상위 GET 복귀를 허용한다. 변경 요청은 기존 동일 출처 검사와 서버 권한 검사를 적용한다.

앱 REST API 키가 바뀌면 기존 앱의 카카오 회원번호와 자동으로 합치지 않는다. 외부 공개·HTTPS 운영 배포·영구 세션 저장소·연결 해제 웹훅은 별도 구성 범위다. 현재는 로컬 개발용이다.

기본 화면은 /, 로그인·추가 가입은 /login, 기존 계정 연결은 /user, 로그인 후 강좌는 /courses, 관리는 /manager로 분리되어 있다. API는 /api 아래에 있으며 공식 callback URI는 기존 값을 유지한다.
