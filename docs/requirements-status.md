## 검사

Mocha 통합 테스트 55개를 통과했다. 기본 API 12개, 카카오 7개, 추가 기능 19개, 소셜·항목 설정 17개다. 로컬 MySQL·HTTP·세션과 실제 FFmpeg·Nginx를 사용하며, 자동화에서는 테스트 편지함과 모의 소셜 응답을 사용한다.

실제 회원가입 화면에서도 Gmail을 통해 코드를 받고 가입 신청을 완료했다. 공유 DB의 회원 상태는 `pending`이고 사용한 인증코드 행은 삭제됐다. 이 확인에는 공유 DB의 유휴 세션 5개 정리와 구형 `signup_codes.sent_at` 열의 `NULL` 허용 변경이 필요했다.

## 평가 라우터

| 모듈     | 주소                              | API 수 |
| -------- | --------------------------------- | ------ |
| info     | `/api/info/qna`                   | 8      |
| courses  | `/api/courses`                    | 6      |
| lectures | `/api/courses/:courseId/lectures` | 8      |
| boards   | `/api/boards`                     | 7      |

manager·auth·user는 회원 관리여서 평가 제외 대상으로 본다. lectures는 별도 Express Router이지만 강좌 아래에 연결되어 있으므로 별도 라우터 인정 여부는 교수 기준을 확인한다. 별칭 경로를 두 개의 구현으로 세지 않는다.

## 남은 연결

1. 기존 중복 닉네임을 정리한 뒤 db:init을 실행해 닉네임 고유 인덱스를 추가한다. 필요한 테이블은 적용했다.
2. Google Cloud OAuth 웹 클라이언트 등록·환경 변수 입력·실계정 확인.
3. 새 공통 서비스의 실제 카카오 인증 확인. 과거 실로그인 기록과 이번 테스트를 구분한다.
4. 팀 영상 공동 재생 서버·HTTPS·영구 세션 저장소가 필요하면 별도로 배포 설계.
